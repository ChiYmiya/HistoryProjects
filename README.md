## 中文

本仓库用于记录个人在不同阶段的学习项目与实践内容，主要包括 Web 开发入门阶段以及大学期间完成的相关项目。

### Web 入门阶段项目  

**仿操作系统界面的静态前端项目**  

- 技术栈：HTML / JavaScript / CSS  
- 通过模拟桌面操作系统界面，练习前端页面结构、交互逻辑以及样式设计。

### 毕业设计项目  

**游戏信息平台**  

- 技术栈：Vue 3 + Spring Boot  
- 实现游戏信息展示与基础管理功能，并完成前后端交互。

### 大学期间练习项目  

- 包含若干学习过程中完成的小型实践项目（示例代码、功能练习等）。

## 日本語

本リポジトリは、学習過程において作成したプロジェクトや実践コードを記録するためのものです。  
主に Web 開発の入門段階および大学在学中に作成したプロジェクトを含みます。

### Web 入門プロジェクト  

**OS風インターフェースを模した静的フロントエンドプロジェクト**  

- 技術スタック：HTML / JavaScript / CSS  
- デスクトップOSのUIを模倣することで、フロントエンドの基本構造、インタラクション、およびスタイル設計を学習。

### 卒業制作プロジェクト  

**ゲーム情報プラットフォーム**  

- 技術スタック：Vue 3 + Spring Boot  
- ゲーム情報の表示および基本的な管理機能を実装し、フロントエンドとバックエンドの連携を実践。

### 大学期間の練習プロジェクト  

- 学習過程で作成した小規模な実践プロジェクト（サンプルコード、機能練習など）を含む。
